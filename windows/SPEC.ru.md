# Sync Watchdog для Windows — задание

Версия для Windows 10/11 того же сторожа, что `Sources/main.swift` (macOS). Логику брать оттуда же, отличаются только способ чтения статуса, установка и интерфейс.

## Что делает (как на Маке)

Раз в 10 минут, для OneDrive и Dropbox, только если программа **установлена** и **включена галочка «следить»**:

1. Процесс не запущен → запустить в фоне, записать в журнал.
2. Запущен → прочитать подсказку (tooltip) значка в трее.
   - «Обновлено / Up to date / Синхронизировано» → в порядке.
   - «Отправка / Uploading / Синхронизация / Syncing / Соединение / Connecting / Обработка / Processing…» → «занят».
   - «Приостановлено / Paused / Нет подключения / Offline / Войдите / Sign in / Ошибка / Error» → не трогать.
   - Неизвестный текст → «в порядке» (не трогать).
3. «Занят» с **одинаковым** текстом 4 проверки подряд (~40 мин работы ПК; сон не считается — считаем проверки, а не часы) → проверить интернет → **один** перезапуск этого клиента → `doneRestart`.
4. После перезапуска снова 4 проверки с тем же «занят» → уведомление + запись «нужен человек», больше не перезапускать, пока текст не сменится (смена текста = новый эпизод, сброс флагов).
5. Каждый запуск перезаписывает `last-check.txt`: время + строка на каждый клиент. Журнал `journal.log` — только когда что-то сделал.

Состояние между запусками — JSON на клиента: `prev`, `cnt`, `doneRestart`, `warned` (как на Маке).

## Технология

- **C# под .NET Framework 4.x**, один файл `windows/src/SyncWatchdog.cs`, WinForms для окна.
- Сборка встроенным в Windows компилятором, без установки SDK: `windows/build.cmd` →
  `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /out:SyncWatchdog.exe /r:UIAutomationClient.dll /r:UIAutomationTypes.dll /r:System.Windows.Forms.dll /r:System.Drawing.dll /r:WindowsBase.dll …`
  (сборки UIAutomation лежат в `…\Framework64\v4.0.30319\WPF\`). Синтаксис C# — **не новее C# 5** (этот csc старый: без `$"..."`, без `?.`, без `nameof`, без expression-bodied членов).
- `/target:winexe` — без чёрного окна консоли при проверках по расписанию.

## Режимы запуска (как на Маке)

- Без аргументов (двойной щелчок) → **установщик / окно статуса**.
- `--check` → одна проверка (так запускает Планировщик).
- `--status` → вывести в файл/консоль: установлен ли, путь, задача есть ли.
- Переменные `FAKE_OneDrive` / `FAKE_Dropbox` подменяют текст статуса (для теста), `STOROZH_VERBOSE=1` — подробный вывод в `%LOCALAPPDATA%\Sync Watchdog\verbose.txt` (winexe не пишет в консоль).

## Установка без прав администратора

При двойном щелчке:

1. Скопировать себя в `%LOCALAPPDATA%\Programs\Sync Watchdog\SyncWatchdog.exe` (если запущен не оттуда); дальше работать из копии.
2. Создать задачу Планировщика для текущего пользователя (админ не нужен):
   `schtasks /Create /F /TN "Sync Watchdog" /SC MINUTE /MO 10 /TR "\"<путь>\" --check" /RL LIMITED`
   Задача должна идти только пока пользователь вошёл (нужен доступ к трею). Проверить, что при сне ПК пропущенные запуски не сыпятся пачкой (если сыпятся — это не страшно, счётчик проверок всё равно корректен, но лучше настроить через XML-задачу с `StartWhenAvailable=false`, `MultipleInstancesPolicy=IgnoreNew`, `ExecutionTimeLimit=PT2M`).
3. Повторный двойной щелчок → окно статуса (см. ниже), задача пересоздаётся (`/F`) на случай переноса.
4. «Удалить» → `schtasks /Delete /F /TN "Sync Watchdog"`, сообщить «теперь удалите папку…» (или удалить её самим через отложенный `cmd /c timeout 2 & rmdir`).

## Окно (WinForms, двуязычное по `CultureInfo.CurrentUICulture`: ru → русский, иначе английский)

- Заголовок «Сторож синхронизации» / «Sync Watchdog».
- Текст: «Сторож включён и работает в фоне, окон не показывает. Раз в 10 минут он проверяет OneDrive и Dropbox и перезапускает их, если они закрылись или зависли.»
- Итог последней проверки строками «• OneDrive — в порядке».
- Галочки «Следить за OneDrive», «Следить за Dropbox». Не установленная программа — галочка выключена и недоступна, подпись «(не установлен)». Сохранять в `settings.json`. По умолчанию включены установленные.
- Галочка **«Всегда показывать значки OneDrive и Dropbox в трее»** (по умолчанию включена, пояснение: «иначе Windows прячет их под стрелку и сторож не видит зависаний») — см. «Скрытый трей».
- Кнопки: OK, «Открыть журнал» (открыть `journal.log` в Блокноте; если файла нет — создать с «Журнал пуст…»), «Удалить сторожа».
- Окно поверх остальных (`TopMost = true`).

## Где лежит

`%LOCALAPPDATA%\Sync Watchdog\`: `journal.log`, `last-check.txt`, `settings.json`, `OneDrive.json`, `Dropbox.json`.
Журнал и last-check — на языке системы (как на Маке, функция `L(ru, en)`).

## Как найти и запустить клиентов

- **OneDrive**: процесс `OneDrive.exe`. Путь: `%LOCALAPPDATA%\Microsoft\OneDrive\OneDrive.exe`, иначе `%ProgramFiles%\Microsoft OneDrive\OneDrive.exe`, иначе `%ProgramFiles(x86)%\…`. Запуск: `OneDrive.exe /background`. Штатное закрытие: `OneDrive.exe /shutdown`.
- **Dropbox**: процесс `Dropbox.exe`. Путь: `%ProgramFiles(x86)%\Dropbox\Client\Dropbox.exe` или `%ProgramFiles%\Dropbox\Client\Dropbox.exe` или `%LOCALAPPDATA%\Dropbox\Client\Dropbox.exe`; запасной вариант — из реестра `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (значение Dropbox). Запуск: `Dropbox.exe /home`. Закрытие: `CloseMainWindow` у всех процессов / `taskkill /IM Dropbox.exe` (без /F), ждать до 60 с, если не закрылся — записать «не закрылся штатно, оставил как есть» (как на Маке, **без /F**).
- Ждать закрытия по самому процессу (`Process.HasExited` / `WaitForExit`), пауза 3 с, запуск.

## Чтение статуса и СКРЫТЫЙ ТРЕЙ (главный риск)

Подсказка значка = `Name` элемента UI Automation кнопки значка в трее. Пример: «OneDrive - Личное\nОбновлено», «Dropbox\nSyncing…». Склеивать строки через пробел.

Где искать (UIAutomation, `AutomationElement.RootElement`):

1. **Видимая часть трея**: окно `Shell_TrayWnd` → потомки-кнопки, у которых `Name` начинается с «OneDrive» / «Dropbox». (Win11: элементы с `ClassName` «SystemTray.NormalButton» или подобные; Win10: `ToolbarWindow32` «Пользовательская область уведомлений».) Искать по `Name.StartsWith`, не завязываться на ClassName — проверить на живом ПК.
2. **Скрытая часть (под стрелкой «^»)**:
   - Win10: окно `NotifyIconOverflowWindow` существует постоянно (скрыто) — попробовать читать его `ToolbarWindow32` без открытия.
   - Win11: панель переполнения существует только когда открыта. **Открывать её программно НЕЛЬЗЯ** — будет мигать у человека каждые 10 минут.
3. **Решение для Win11 — показать значки постоянно**: Windows 11 22H2+ хранит настройки значков в `HKCU\Control Panel\NotifyIconSettings\<число>\` (значения `ExecutablePath`, `IsPromoted`). Найти подключи, где `ExecutablePath` оканчивается на `OneDrive.exe` / `Dropbox.exe`, выставить `IsPromoted` = 1 (DWORD). Делать только если включена галочка «Всегда показывать значки». Это то же, что человек сделал бы руками в «Параметры → Персонализация → Панель задач → Другие значки». Проверить, подхватывает ли Explorer сразу или после перезапуска клиента.
4. Если значок так и не найден → статус «значок не найден в трее» (в last-check), журнал — один раз за эпизод; перезапуск только по «процесс не запущен» (как на Маке при `.notFound`).

## Уведомление «снова завис»

`NotifyIcon` + `ShowBalloonTip` на ~10 с, затем выход (в Win10/11 показывается как обычное уведомление). Или toast через PowerShell — на выбор, главное без внешних библиотек.

## Проверка интернета перед перезапуском

HTTP GET `http://www.msftconnecttest.com/connecttest.txt` (ответ «Microsoft Connect Test»), запасной — `http://captive.apple.com`. Таймаут 10 с. Нет интернета → не перезапускать.

## План проверки на Windows 11 (с Антоном)

1. Собрать `build.cmd`, запустить `SyncWatchdog.exe` двойным щелчком → установился, задача есть (`schtasks /Query /TN "Sync Watchdog"`).
2. **Собрать реальные тексты подсказок**: `--status` (или отдельный `--dump-tray`) печатает все `Name` кнопок трея — видимых и, если удаётся, скрытых. Снять в состояниях: обновлено, идёт отправка (кинуть файл 100 МБ), пауза, без сети. Дополнить слова в `classify()`.
3. Значок OneDrive/Dropbox **спрятан под стрелку** → проверить, что галочка «Всегда показывать значки» его вытаскивает и статус читается.
4. Имитация: `set FAKE_Dropbox=Dropbox Connecting...` + 5 × `SyncWatchdog.exe --check` → один перезапуск; ещё 4 → уведомление, без перезапуска.
5. Только Dropbox / только OneDrive: снять галочку → клиент не трогается; закрыть клиент вручную → сторож его не поднимает.
6. Сон ПК 30+ минут → после пробуждения проверки идут, ложного перезапуска нет.
7. Нагрузка: время одной проверки (< 1 с), CPU в Диспетчере задач.
