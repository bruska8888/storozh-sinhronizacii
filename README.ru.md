# Сторож синхронизации (Sync Watchdog) для macOS

[English](README.md) | **Русский**

**Сторож синхронизации следит, чтобы OneDrive и Dropbox на Маке продолжали работать после сна, закрытия крышки ноутбука и гибернации.**

После пробуждения Мака OneDrive и Dropbox часто тихо перестают синхронизировать файлы. Бывает, что программа закрылась при самообновлении, пока Мак спал. Бывает, что она открыта, но отправка часами стоит на «Отправка файлов (2%)» или «Соединение...». Замечаешь это, только когда на другом компьютере не оказалось нужного файла.

Сторож раз в 10 минут проверяет обе программы в фоне. Закрылась — запускает снова. Зависла — один раз перезапускает. Не помогло — показывает уведомление.

---

## Установка

1. Скачайте **`SyncWatchdog-<версия>.dmg`** со страницы [Releases](../../releases/latest).
2. Откройте `.dmg` и перетащите **Sync Watchdog** в папку **«Программы»**.
3. Откройте **Сторож синхронизации** из «Программ». На русской системе он называется так, файл — `Sync Watchdog.app`.

### Первый запуск: предупреждение Apple

Приложение не подписано платным сертификатом Apple Developer, поэтому при первом запуске macOS напишет *«Не удалось открыть „Sync Watchdog“»* или *«Apple не удалось проверить…»*. Так и должно быть. Чтобы разрешить запуск, сделайте один раз:

1. Нажмите **«Готово»** (или **«ОК»**) в этом сообщении.
2. Откройте **Системные настройки → Конфиденциальность и безопасность**.
3. Прокрутите вниз до раздела **«Безопасность»**. Рядом с надписью *«Использование „Sync Watchdog“ было заблокировано…»* нажмите **«Всё равно открыть»**.
4. Подтвердите паролем или Touch ID и ещё раз нажмите **«Всё равно открыть»**.

macOS спрашивает это только один раз. Дальше приложение открывается как обычное.

### Два переключателя

При первом запуске сторож сам ставит себя на работу в фоне и просит два разрешения:

- **«Универсальный доступ»** (*Системные настройки → Конфиденциальность и безопасность → Универсальный доступ*). Включите **«Сторож синхронизации»**. Так он сможет читать подпись у значков OneDrive и Dropbox в строке меню. Без этого разрешения сторож перезапускает закрывшиеся программы, но не видит, что они зависли.
- **«Разрешить в фоне»** (*Системные настройки → Основные → Объекты входа*). Обычно включено само, macOS просто покажет уведомление. Если там у сторожа переключатель выключен — включите.

Всё. После каждой перезагрузки Мака сторож запускается сам.

## Как пользоваться

У сторожа нет окон и значка в строке меню. Чтобы посмотреть, что он делает, откройте его из «Программ». Появится окно:

- работает ли сторож;
- итог последней проверки, например *• OneDrive — в порядке*;
- **«Открыть журнал»** — история всего, что он делал: запуски, перезапуски, предупреждения;
- **«Удалить сторожа»** — выключает его. После этого перетащите приложение в Корзину.

## Обновление

Скачайте новый `.dmg`, перетащите приложение в «Программы», выберите **«Заменить»** и откройте его один раз. Удалять старую версию заранее не нужно. Если macOS снова спросит про «Универсальный доступ», включите переключатель.

## Как это работает (подробно)

macOS (`launchd`) запускает сторожа раз в 10 минут. Он делает одну проверку за долю секунды и выходит.

| Что видит | Что делает |
|---|---|
| OneDrive/Dropbox не запущен | Запускает в фоне |
| Статус «Выполнено…» / «Обновлено» | Ничего |
| «Отправка…», «Соединение…», «Синхронизация…», и текст меняется | Ничего, работа идёт |
| Тот же текст «Отправка…» / «Соединение…» **4 проверки подряд (~40 мин)** | Проверяет интернет, затем **один раз** штатно перезапускает только эту программу |
| После перезапуска снова завис так же | Уведомление и запись в журнал. Больше не трогает, пока статус не сменится |
| Пауза, нет сети, нужен вход в аккаунт | Ничего |

Время сна Мака не считается: «40 минут» — это 40 минут, пока Мак не спит.

Статус — это текст значка в строке меню, та же подсказка, что видна при наведении мыши. Сторож читает его через Accessibility API macOS. Нагрузки почти нет: два коротких запроса раз в 10 минут. Файлы сторож не перебирает и в сеть не ходит, кроме одной проверки интернета перед перезапуском.

Окна, уведомления, журнал и название приложения — на языке системы, русском или английском.

### Файлы

Всё хранится на самом Маке. Никуда не отправляется, облако и аккаунты не нужны.

| Что | Где |
|---|---|
| Приложение | `/Applications/Sync Watchdog.app` |
| Последняя проверка (перезаписывается каждый раз) | `~/Library/Logs/Sync Watchdog/last-check.txt` |
| Журнал действий (только когда что-то сделал) | `~/Library/Logs/Sync Watchdog/journal.log` |
| Состояние между запусками | `~/Library/Application Support/Sync Watchdog/` |

Журнал можно открыть и в программе **«Консоль»**: *Отчёты журналов → Sync Watchdog*.

### Требования

macOS 13 Ventura или новее. Apple Silicon и Intel (сборка для Intel не проверялась).

## Для разработчиков

Сборка из исходника. Нужны Command Line Tools от Apple (`xcode-select --install`), полный Xcode не нужен:

```bash
./build.sh      # → build/Sync Watchdog.app и dist/SyncWatchdog-<версия>.dmg
./install.sh    # собрать, положить в /Applications и открыть
```

`build.sh` подписывает приложение сертификатом «Apple Development», если он есть в связке ключей. Тогда разрешение «Универсальный доступ» переживает пересборку. Иначе ставится временная подпись, и после каждой пересборки разрешение придётся выдавать заново. Если переключатель включён, а доступа нет, удалите приложение из списка «Универсального доступа» кнопкой «−» и откройте его снова.

Диагностика:

```bash
"/Applications/Sync Watchdog.app/Contents/MacOS/SyncWatchdog" --status
```

Проверка без настоящего зависания (`FAKE_<программа>` подменяет статус):

```bash
B="/Applications/Sync Watchdog.app/Contents/MacOS/SyncWatchdog"
for i in 1 2 3 4 5; do FAKE_Dropbox="Dropbox Соединение..." STOROZH_VERBOSE=1 "$B"; done
```

На 5-м запуске Dropbox по-настоящему перезапустится. Ещё 4 запуска дадут уведомление «снова завис». Обычный запуск сбрасывает эпизод.

Настройки в `Sources/main.swift`: `APPS` (какие программы проверять), `POROG` (сколько проверок без изменений считается зависанием), `classify()` (какие слова статуса означают «занят», «пауза», «в порядке», на русском и английском).
