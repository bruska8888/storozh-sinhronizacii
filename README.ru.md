# Сторож синхронизации (Sync Watchdog) для macOS и Windows

[English](README.md) | **Русский**

**Сторож синхронизации следит, чтобы OneDrive и Dropbox на Маке или компьютере с Windows продолжали работать после сна, закрытия крышки ноутбука и гибернации.**

**Мак:** [установка](#установка-на-мак) · **Windows 10/11:** [установка](#windows-1011)

После пробуждения компьютера OneDrive и Dropbox часто тихо перестают синхронизировать файлы. Бывает, что программа закрылась при самообновлении, пока Мак спал. Бывает, что она открыта, но отправка часами стоит на «Отправка файлов (2%)» или «Соединение...». Замечаешь это, только когда на другом компьютере не оказалось нужного файла.

Сторож раз в 10 минут проверяет обе программы в фоне. Можно, чтобы была установлена только одна из них. Закрылась — запускает снова. Зависла — один раз перезапускает. Не помогло — показывает уведомление.

---

## Установка на Мак

1. Скачайте **`SyncWatchdog-<версия>.dmg`** со страницы [Releases](../../releases/latest).
2. Откройте `.dmg` и перетащите **Sync Watchdog** в папку **«Программы»**.
3. Откройте **Сторож синхронизации** из «Программ». На русской системе он называется так, файл — `Sync Watchdog.app`.

### Первый запуск: предупреждение Apple

Приложение не подписано платным сертификатом Apple Developer, поэтому при первом запуске macOS напишет *«Не удалось открыть „Sync Watchdog“»* или *«Apple не удалось проверить…»*. Так и должно быть. Чтобы разрешить запуск, сделайте один раз:

1. Нажмите **«Готово»** (или **«ОК»**) в этом сообщении.
2. Откройте **Системные настройки → Конфиденциальность и безопасность**.
3. Прокрутите вниз до раздела **«Безопасность»**. Рядом с надписью *«Использование „Sync Watchdog“ было заблокировано…»* нажмите **«Всё равно открыть»**.
4. Подтвердите паролем или Touch ID и ещё раз нажмите **«Всё равно открыть»**.

macOS спрашивает это только один раз. Дальше приложение открывается как обычное.

### Два переключателя

При первом запуске сторож сам ставит себя на работу в фоне и просит два разрешения:

- **«Универсальный доступ»** (*Системные настройки → Конфиденциальность и безопасность → Универсальный доступ*). Включите **«Сторож синхронизации»**. Так он сможет читать подпись у значков OneDrive и Dropbox в строке меню. Без этого разрешения сторож перезапускает закрывшиеся программы, но не видит, что они зависли.
- **«Разрешить в фоне»** (*Системные настройки → Основные → Объекты входа*). Обычно включено само, macOS просто покажет уведомление. Если там у сторожа переключатель выключен — включите.

Всё. После каждой перезагрузки Мака сторож запускается сам.

## Как пользоваться

У сторожа нет окон и значка в строке меню. Чтобы посмотреть, что он делает, откройте его из «Программ». Появится окно:

- работает ли сторож;
- итог последней проверки, например *• OneDrive — в порядке*;
- галочки **«Следить за OneDrive»** и **«Следить за Dropbox»**. Если какую-то программу вы держите выключенной специально, снимите галочку, и сторож не будет её трогать. Если установлена только одна из программ, вторая просто пропускается;
- **«Открыть журнал»** — история всего, что он делал: запуски, перезапуски, предупреждения;
- **«Удалить сторожа»** — выключает его. После этого перетащите приложение в Корзину.

## Обновление

Скачайте новый `.dmg`, перетащите приложение в «Программы», выберите **«Заменить»** и откройте его один раз. Удалять старую версию заранее не нужно. Если macOS снова спросит про «Универсальный доступ», включите переключатель.

## Windows 10/11

### Установка

1. Скачайте **`SyncWatchdog-<версия>.exe`** со страницы [Releases](../../releases/latest).
2. Запустите его. Программа не подписана платным сертификатом, поэтому при первом запуске Windows может написать *«Windows защитила ваш компьютер»*. Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**. Windows спрашивает это только один раз.
3. Нажмите **«Установить»**. Права администратора не нужны.

Сторож копирует себя в `%LOCALAPPDATA%\Programs\Sync Watchdog`, сразу начинает работать в фоне и появляется в меню **«Пуск»** как *«Сторож синхронизации»* и в **«Параметры → Приложения → Установленные приложения»**. Скачанный файл больше не нужен, его можно удалить.

### Как пользоваться

Значка в трее нет. Сторожа раз в 10 минут запускает Планировщик заданий Windows, одна проверка длится около секунды. Чтобы посмотреть, что он делает, откройте **«Сторож синхронизации»** из меню «Пуск»:

- итог последней проверки, например *• OneDrive — в порядке*;
- галочки **«Следить за OneDrive»** и **«Следить за Dropbox»** — как на Маке;
- **«Всегда показывать значки OneDrive и Dropbox на панели задач»** (включено по умолчанию). Windows прячет значки трея под стрелку **«^»**, а статус сторож может прочитать только у видимого значка. С этой галочкой он сам возвращает оба значка на панель. Без неё закрывшуюся программу сторож всё равно поднимет, но зависание не заметит;
- **«Открыть журнал»** и **«Удалить сторожа»**.

### Обновление и удаление

- **Обновить:** запустите новый `.exe` и нажмите **«Обновить»**. Настройки и журнал сохраняются.
- **Удалить:** *«Параметры → Приложения → Установленные приложения → Сторож синхронизации → Удалить»* или кнопка в окне. Удаляется всё: задача Планировщика, ярлык в «Пуске», программа, журнал и настройки.

### Как это работает в Windows

Правила те же, что на Маке (таблица ниже): закрывшийся клиент запускается; один и тот же статус «занят» 4 проверки подряд — один перезапуск; снова завис — уведомление.

- Статус — подсказка значка в трее, сторож читает её через UI Automation Windows. Скрытую панель под «^» он никогда не открывает.
- Перезапуск всегда штатный, без принуждения: OneDrive получает `/shutdown`, а Dropbox сторож просит закрыться через Restart Manager Windows — так Windows закрывает программы перед установкой обновлений. Если программа не закрылась, её оставляют как есть.
- Время сна компьютера не считается: сторож считает проверки, а не минуты, и пропущенные во сне запуски после пробуждения не выполняются.
- Окна, журнал и уведомления — на языке системы: на русской Windows по-русски, на любой другой по-английски.

| Что | Где |
|---|---|
| Программа | `%LOCALAPPDATA%\Programs\Sync Watchdog\SyncWatchdog.exe` |
| Последняя проверка (перезаписывается каждый раз) | `%LOCALAPPDATA%\Sync Watchdog\last-check.txt` |
| Журнал действий | `%LOCALAPPDATA%\Sync Watchdog\journal.log` |
| Настройки и состояние | `%LOCALAPPDATA%\Sync Watchdog\settings.json`, `OneDrive.json`, `Dropbox.json` |
| Расписание | Планировщик заданий → *Sync Watchdog* |

Требования: Windows 10 или 11, 64-разрядная (.NET Framework 4.x уже есть в Windows). Проверено на Windows 11.

## Как это работает на Маке (подробно)

macOS (`launchd`) запускает сторожа раз в 10 минут. Он делает одну проверку за долю секунды и выходит.

| Что видит | Что делает |
|---|---|
| OneDrive/Dropbox не запущен | Запускает в фоне |
| Статус «Выполнено…» / «Обновлено» | Ничего |
| «Отправка…», «Соединение…», «Синхронизация…», и текст меняется | Ничего, работа идёт |
| Тот же текст «Отправка…» / «Соединение…» **4 проверки подряд (~40 мин)** | Проверяет интернет, затем **один раз** штатно перезапускает только эту программу |
| После перезапуска снова завис так же | Уведомление и запись в журнал. Больше не трогает, пока статус не сменится |
| Пауза, нет сети, нужен вход в аккаунт | Ничего |

Время сна Мака не считается: «40 минут» — это 40 минут, пока Мак не спит.

Статус — это текст значка в строке меню, та же подсказка, что видна при наведении мыши. Сторож читает его через Accessibility API macOS. Нагрузки почти нет: два коротких запроса раз в 10 минут. Файлы сторож не перебирает и в сеть не ходит, кроме одной проверки интернета перед перезапуском.

Окна, уведомления, журнал и название приложения — на языке системы, русском или английском.

### Файлы

Всё хранится на самом Маке. Никуда не отправляется, облако и аккаунты не нужны.

| Что | Где |
|---|---|
| Приложение | `/Applications/Sync Watchdog.app` |
| Последняя проверка (перезаписывается каждый раз) | `~/Library/Logs/Sync Watchdog/last-check.txt` |
| Журнал действий (только когда что-то сделал) | `~/Library/Logs/Sync Watchdog/journal.log` |
| Настройки и состояние между запусками | `~/Library/Application Support/Sync Watchdog/` |

Журнал можно открыть и в программе **«Консоль»**: *Отчёты журналов → Sync Watchdog*.

### Требования

macOS 13 Ventura или новее. Apple Silicon и Intel (версия для Intel проверена под Rosetta, на настоящем Intel-Маке — ещё нет).

## Для разработчиков

Сборка из исходника. Нужны Command Line Tools от Apple (`xcode-select --install`), полный Xcode не нужен:

```bash
./build.sh      # → build/Sync Watchdog.app и dist/SyncWatchdog-<версия>.dmg
./install.sh    # собрать, положить в /Applications и открыть
```

`build.sh` подписывает приложение самоподписанным сертификатом «Sync Watchdog», если он есть в связке ключей. Тогда разрешение «Универсальный доступ» переживает обновления. Иначе ставится временная подпись, и после каждой пересборки разрешение придётся выдавать заново. Личным сертификатом «Apple Development» не подписывать: в нём почта владельца. `build.sh` остановится, если найдёт в подписи адрес почты. Если переключатель включён, а доступа нет, удалите приложение из списка «Универсального доступа» кнопкой «−» и откройте его снова.

Расписание — обычный LaunchAgent (`~/Library/LaunchAgents/com.anton.storozh-sinhronizacii.plist`), его пишет само приложение при открытии. Новый механизм Apple `SMAppService` пробовали в 1.1–1.2, но такие агенты launchd запускает только у приложений с подписью от Apple.

Диагностика:

```bash
"/Applications/Sync Watchdog.app/Contents/MacOS/SyncWatchdog" --status
```

Проверка без настоящего зависания (`FAKE_<программа>` подменяет статус):

```bash
B="/Applications/Sync Watchdog.app/Contents/MacOS/SyncWatchdog"
for i in 1 2 3 4 5; do FAKE_Dropbox="Dropbox Соединение..." STOROZH_VERBOSE=1 "$B"; done
```

На 5-м запуске Dropbox по-настоящему перезапустится. Ещё 4 запуска дадут уведомление «снова завис». Обычный запуск сбрасывает эпизод.

Версия для Windows — один файл на C#, собирается компилятором, который уже есть в Windows (без SDK и прав администратора). Подробности — [`windows/README.md`](windows/README.md):

```bat
windows\build.cmd
```

Настройки в `Sources/main.swift`: `APPS` (какие программы проверять), `POROG` (сколько проверок без изменений считается зависанием), `classify()` (какие слова статуса означают «занят», «пауза», «в порядке», на русском и английском).
