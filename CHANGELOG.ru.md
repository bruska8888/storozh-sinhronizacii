# Список изменений

[English](CHANGELOG.md) | **Русский**

## 1.5.1 — 2026-11-18
- Windows: в заголовке уведомлений теперь «Sync Watchdog», а не имя файла (сразу после обновления там было «SyncWatchdog.exe.old»). У exe появились нормальные свойства файла: название и версия.
- Автообновление 1.4.9 → 1.5 проверено на живом компьютере: скачивание, проверка подписи, замена, уведомление.

## 1.5 — 2026-11-18
- Windows: **автообновление** из GitHub Releases раз в сутки. Галочка **«Обновлять автоматически»** (включена по умолчанию); без неё — уведомление и кнопка **«Обновить до …»**. Кнопка **«Проверить обновления»** в окне.
- Windows: у каждого обновления должна быть верная подпись RSA-SHA256 (`.sig` рядом с `.exe`); неподписанный или изменённый файл не ставится.
- Windows: свой значок (файл, «Пуск», «Установленные приложения», окно, уведомления).
- Репозиторий открыт, лицензия MIT.

## 1.4 — 2026-11-18
- **Версия для Windows 10/11** (`SyncWatchdog-1.4.exe`). Правила те же, что на Маке. Окно установки с кнопками **«Установить» / «Обновить»**, права администратора не нужны; сторож появляется в меню «Пуск» и в «Параметры → Приложения → Установленные приложения», откуда удаляется целиком.
- Windows: статус читается из подсказки значка в трее через UI Automation; галочка **«Всегда показывать значки OneDrive и Dropbox на панели задач»** возвращает значки из-под стрелки «^», чтобы зависания были видны.
- Windows: перезапуск только штатный — OneDrive `/shutdown`, Dropbox через Restart Manager Windows.
- Windows: слова статуса, найденные на живом компьютере: OneDrive «Поиск изменений», «Скачивание файлов», «Обработка изменения»; Dropbox «Обновление файлов». Подсказку OneDrive из нескольких строк сторож оценивает по строкам.
- Приложение для Мака не менялось (в `.dmg` по-прежнему 1.3).

## 1.3 — 2026-11-17
- Приложение подписано нейтральным сертификатом «Sync Watchdog», личных данных в подписи нет.
- Расписание — обычный LaunchAgent, его пишет само приложение. `SMAppService` launchd не запускает без подписи от Apple. Теперь сторож действительно работает на любом Маке.
- После обновления с 1.1–1.2: открыть приложение один раз и заново включить «Универсальный доступ» (подпись сменилась).

## 1.2 — 2026-11-17
- Галочки **«Следить за OneDrive» / «Следить за Dropbox»** в окне приложения. Снимите галочку, если держите программу выключенной специально, — сторож не будет её запускать. Не установленные программы пропускаются сами.
- Маки на Intel: проверено под Rosetta (чтение статуса, имитация зависания, перезапуск).

## 1.1 — 2026-11-17
- Установка одним файлом: скачать `.dmg`, перетащить в «Программы», открыть. Приложение само ставит себя на расписание и просит разрешения. Терминал не нужен.
- Запускается само после перезагрузки (Объекты входа → «Разрешить в фоне»).
- Если открыть приложение, оно показывает, работает ли сторож и итог последней проверки. Есть кнопки «Открыть журнал» и «Удалить сторожа».
- Новое имя файла — `Sync Watchdog.app`, на русской системе он называется «Сторож синхронизации».
- Журнал и сообщения — на языке системы, английском или русском. Файлы переехали в `~/Library/Logs/Sync Watchdog/`, старые переносятся сами.
- Обновление поверх старой версии не ломает расписание: при каждом открытии приложение перерегистрирует себя.
- Сборка для Apple Silicon и Intel, macOS 13 и новее.

## 1.0 — 2026-11-17
- Отдельное приложение «Сторож синхронизации» вместо zsh-скрипта. Разрешение «Универсальный доступ» выдаётся только ему, а не всем zsh-скриптам.
- Ловит «живой, но зависший» клиент: тот же текст «Отправка…» или «Соединение…» 40 минут подряд → один перезапуск; снова завис → уведомление.
- Файл «последней проверки» `last-check.txt`: по нему видно, что сторож работал и что видел.
- Подпись сертификатом Apple Development: разрешение не сбрасывается при пересборке.
- Исправлено: при перезапуске сторож не замечал, что клиент уже закрылся.
- Интерфейс (уведомления, название) на русском и английском.

## 0.2 — 2026-11-16 (zsh-скрипт)
- Первая проверка зависания по тексту значка в строке меню. Поймала Dropbox, висевший на «Соединение...» с 17:09.

## 0.1 — 2026-11-13 (zsh-скрипт)
